# AGENTS.md

Instructions for AI coding agents working in this repository. `CLAUDE.md` holds the detailed guidance for this repo; read it first.

## Rules

- Work on a feature branch. Never push directly to the default branch.
- Run the repo's own checks before pushing (commands are in `CLAUDE.md`).
- Never commit secrets. Put placeholder values in `.env.example`.
- Record user-visible changes in `CHANGELOG.md` under `[Unreleased]`.
- Don't change `LICENSE`, `SECURITY.md`, or `VERSION.md` without an explicit request.
