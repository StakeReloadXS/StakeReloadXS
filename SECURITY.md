# Security Policy

## Reporting a vulnerability

Do not open a public issue for security problems.

Report privately: open this repository's **Security** tab and choose **Report a vulnerability**. Include the affected component, steps to reproduce, and the expected impact.

## Supported versions

Only the latest release on the default branch receives security fixes.

## Secrets

Never include live credentials, tokens, or customer data in issues, pull requests, logs, or commits.
