## Before posting
1. Search for an existing discussion and react or reply rather than posting duplicates.
2. Use a specific title and describe what you expected, what happened, and why it matters.
3. Include platform/browser information for technical issues. Screenshots should hide identifiers.
4. Never share account credentials, order IDs associated with identity, payment information, government IDs, private messages, or other personal data in public posts.
5. For account/payment/verification disputes or sensitive support, use an official private support channel listed on the [website](https://stakereloadxs.com/support.html), not GitHub Discussions.

## Feature request format
**Problem:** What is difficult or missing?

**Proposal:** What would improve it?

**Who benefits:** Which participants would use it?

**Example journey:** What would the user do from start to finish?

**Alternatives:** What workarounds have you tried?

**Privacy/security considerations:** Can this be delivered safely?

## Moderation and transparency
Be respectful; criticize ideas, not people. No harassment, threats, hate, spam, referral advertising, impersonation, doxxing, or posting another person's personal information. No instructions to bypass verification, abuse accounts, or exploit services. Moderators may hide or remove posts that violate these rules, request clarification, and lock repetitive or abusive threads.

Reactions and polls are signals, not guarantees of implementation. Maintainers should acknowledge new requests, tag or record their status (Under review, Planned, In progress, Shipped, Declined), explain tradeoffs where feasible, and link implementation Issues or PRs. Do not publicly expose security weaknesses: report privately to maintainers using a documented secure channel.

## Participation lifecycle
Post → Community discussion and reactions → Maintainer triage → Decision and rationale → Linked implementation → Release announcement → Requester follow-up.

Community discussions are public and may appear in search engines. Contributions do not grant access to private customer information.
