## What StakeReloadXS is

A set of tools that connect to a StakeReloadXS server, so you can run the tooling in the way that suits you:

- **Self-hosted:** run the server on your own infrastructure.
- **Cloud-hosted:** use a server the operator runs for you.
- **On-demand:** use an instance that is started when needed. Details `UNKNOWN`.

## How getting started will work

1. Install the package.
2. Complete a short setup: check any existing account, optionally link Telegram notifications, and create or link a web account.
3. Choose how to access licensed features. Details `UNKNOWN` pending legal review.
4. Top up a balance with a hosted invoice on the web, from the command line, or through Telegram.
