# Version

Current version: **0.1.0**

Keep this file in sync with `package.json` (where present) and `CHANGELOG.md`.

## Scheme

Semantic Versioning (MAJOR.MINOR.PATCH):

- MAJOR: breaking changes to a public interface.
- MINOR: backwards-compatible additions.
- PATCH: backwards-compatible fixes.

Releases before 1.0.0 may change interfaces in any minor release.
