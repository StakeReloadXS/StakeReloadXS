# StakeReloadXS

**Xtremely simple tools, transparent updates, and a community-led roadmap.**

[Website](https://stakereloadxs.com) · [Community discussions](https://github.com/StakeReloadXS/StakeReloadXS/discussions) · [Feature requests](https://github.com/StakeReloadXS/StakeReloadXS/discussions/categories/ideas) · [Documentation](docs/README.md) · [Issues](https://github.com/StakeReloadXS/StakeReloadXS/issues)

StakeReloadXS is the public home for project documentation, community feedback, and cross-repository planning. The web storefront is a separate project; client applications and developer integrations are at different stages of development.

> **Project status:** The [storefront](https://stakereloadxs.com) is publicly accessible. That does not imply that automated ordering, SDK packages, browser extensions, account balances, or subscriptions are available. See [product status](docs/PRODUCTS.md) and the live website for current information. Product offerings and terms are subject to review; this repository is not a payment channel.

## Community

We welcome participants, testers, designers, documentation contributors, and experienced developers.

- **Feature requests:** Search existing discussions first, then describe the problem, desired outcome, and your use case. Keep one proposal per discussion.
- **Questions and feedback:** Explain what you tried, what happened, and what would help.
- **Bugs:** Open an issue with reproduction steps, expected and actual behavior, and non-sensitive environment details.
- **Contributions:** Discuss major changes before implementing them; link pull requests to their issue or discussion.

See [how to participate](docs/COMMUNITY.md). Please be respectful and never disclose passwords, API keys, payment credentials, private account information, or someone else's personal data.

## Safety, authenticity, and terms

Only use links verified through this repository or the official website. Be cautious of unsolicited direct messages and never provide authentication codes or credentials to anyone claiming to represent the project. Do not post vulnerabilities in public discussions; use GitHub's private vulnerability reporting if enabled, or request a private reporting channel without disclosing exploit details.

The website's [Terms of Use](https://stakereloadxs.com/terms.html), [Privacy Policy](https://stakereloadxs.com/privacy.html), and [Refund Policy](https://stakereloadxs.com/refund.html) govern their respective subjects.
